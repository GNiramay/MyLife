# MyLife
Minimal offline-first Android PWA for personal daily-event time-stamping.

## Deployment to GitHub Pages
1. Push repository files to your GitHub repository.
2. In Repository Settings > Pages, select branch main and root folder, then Save.
3. App is live at `https://gniramay.github.io/MyLife/`.

## Android Installation
1. Visit the GitHub Pages URL in Android Chrome.
2. Tap menu (⋮) -> "Install app" / "Add to Home screen". Works 100% offline.

## Features & Export
Log events, view sleep/time graphs, manage buttons, and export CSV data.
